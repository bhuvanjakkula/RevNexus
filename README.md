## 🚢 Production Deployment Guide

### 1. Deploy on Vercel (Edge & Serverless)

RevNexus AI is pre-configured with `vercel.json` for zero-configuration, instant deployment on Vercel:

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new)

**Manual Vercel CLI Deployment:**
```bash
# 1. Install Vercel CLI (if not already installed)
npm install -g vercel

# 2. Deploy directly from repository root
vercel --prod
```
- **Build Command**: None (or `npm run build`)
- **Output Directory**: `.` (Root)
- **Framework**: Other / None

---

### 2. Deploy on Render (Web Service)

RevNexus AI includes a native `render.yaml` blueprint:

1. Create a free account at [render.com](https://render.com).
2. Connect your GitHub repository.
3. Select **New Web Service** (or use the Blueprint from `render.yaml`).
4. Configure settings:
   - **Environment**: `Node`
   - **Build Command**: `npm install`
   - **Start Command**: `npm start`
   - **Plan**: `Free` or `Starter`
5. Render automatically binds to `process.env.PORT` and launches the platform.

---

### 3. Deploy via Git & GitHub

```bash
# 1. Add your remote GitHub repository
git remote add origin https://github.com/YOUR_USERNAME/revnexus-ai.git

# 2. Rename branch to main
git branch -M main

# 3. Push all code to GitHub
git push -u origin main
```

Once pushed to GitHub, both **Vercel** and **Render** can automatically build and deploy every commit via continuous integration (CI/CD).
